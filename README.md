# World Insight

World Insight は、ニュースを材料に、読者の判断力と思考力を鍛えるための独立したプロジェクトです。結論を配るのではなく、事実、異なる立場、トレードオフ、前提、不確実性を整理し、読者自身の判断につながる問いを届けます。

> 世界には、答えより問いがある。

## World Brief との違い

- World Brief：世界で何が起きたかを知る。
- World Insight：その出来事をどう考えるかを鍛える。

両者のブランド、サイト、公開物は分離します。

## 現在地

現在は Foundation フェーズです。理念、編集方針、思考フレームワーク、プロジェクト仕様、情報源方針、制作運用を文書として整備しています。HTML、CSS、Python、公開サイトはまだ実装していません。
